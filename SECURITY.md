# Security Policy

## Supported Scope

This repository is a benchmarking project and not a hosted production service.
Security issues are still welcome, especially when they affect:

- secret handling
- unsafe execution behavior
- sandbox escapes
- file-system safety
- dependency risk
- prompt or tool-invocation trust boundaries

## Reporting

Please do not open a public issue for sensitive vulnerabilities.

Report security concerns privately to the maintainer before public disclosure.

## What Helps

Include:

- a clear description of the issue
- affected files or commands
- reproduction steps
- impact assessment
- any suggested mitigation
