# AutoGen

This directory contains benchmark implementations built with Microsoft AutoGen (`pyautogen`).

Official references used for this implementation:

- AutoGen documentation: [microsoft.github.io/autogen](https://microsoft.github.io/autogen/stable/user-guide/core-user-guide/index.html)
- ConversableAgent & tool registration: `AssistantAgent`, `UserProxyAgent`, and `autogen.agentchat.register_function`

Current implementation:

- `intake-triage/`: benchmark implementation for the `intake_triage` task
