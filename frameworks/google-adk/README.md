Official references used for this implementation:

- Installation: [google.github.io/adk-docs/get-started/installation/](https://google.github.io/adk-docs/get-started/installation/)
- Python quickstart: [google.github.io/adk-docs/get-started/python/](https://google.github.io/adk-docs/get-started/python/)
- Multi-tool quickstart: [google.github.io/adk-docs/get-started/quickstart/](https://google.github.io/adk-docs/get-started/quickstart/)
- LLM agents: [google.github.io/adk-docs/agents/llm-agents/](https://google.github.io/adk-docs/agents/llm-agents/)
- Models and authentication: [google.github.io/adk-docs/agents/models/](https://google.github.io/adk-docs/agents/models/)

- `intake-triage/`: benchmark implementation for the `intake_triage` task
