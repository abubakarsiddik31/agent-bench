# OpenAI Agents SDK

Official references used for this implementation:

- Quickstart: [openai.github.io/openai-agents-python/quickstart/](https://openai.github.io/openai-agents-python/quickstart/)
- Running agents: [openai.github.io/openai-agents-python/running_agents/](https://openai.github.io/openai-agents-python/running_agents/)
- Results and usage: [openai.github.io/openai-agents-python/results/](https://openai.github.io/openai-agents-python/results/) and [openai.github.io/openai-agents-python/usage/](https://openai.github.io/openai-agents-python/usage/)

Current implementation:

- `intake-triage/`: benchmark implementation for the `intake_triage` task
